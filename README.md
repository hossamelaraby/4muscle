# 4 Muscle Drops — متجر قطرات التحلية الصحية

موقع التجارة الإلكترونية الرسمي لمنتج **4 Muscle Healthy Sugar Drops**، مبني بأحدث تقنيات الويب (Next.js 14, TypeScript, Tailwind CSS) مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (`dir="rtl"`). تم تصميم المتجر خصيصاً ليكون جاهزاً للرفع المباشر على **Vercel** والربط مع قاعدة بيانات **Supabase**.

---

## 🌟 مميزات المشروع

1. **تصميم عربي أصيل وفاخر (Arabic-First & RTL):**
   - خط **Cairo** المعتمد مع تباعد أسطر وتنسيقات طباعية مريحة للعين.
   - لوحة ألوان مستوحاة من الهوية البصرية للعلامة التجارية (الأخضر الصحي، الذهبي الدافئ، الرمادي الهادئ، وخلفيات رخام الترافرتين الطبيعي).
   - متوافق 100% مع جميع أحجام الشاشات (الهواتف المحمولة 390px، الأجهزة اللوحية، وشاشات سطح المكتب).

2. **عناصر المتجر وتجربة المستخدم (UX/UI):**
   - **شريط الإعلانات المتحرك (Announcement Bar):** شريط علوي سلس يكرر العروض ويتوقف مؤقتاً عند التمرير أو التركيز.
   - **الترويسة التفاعلية (Header):** تتضمن شعار 4 Muscle الأصلي، روابط التنقل، أيقونة السلة بعدد العناصر، وزر الطلب السريع مع قائمة هاتف منسدلة.
   - **واجهة البطل (Hero Section):** تكوين ثنائي يبرز عبوة المنتج الطبيعية مع نقاط التحلية (400 نقطة) ومزايا الذوبان الفوري.
   - **بطاقات المزايا (Benefit Cards):** 4 بطاقات تفاعلية سهلة التمرير في الجوال ومصطفة أفقياً على الحاسوب.
   - **مقارنة المشاكل والحلول (Problem to Solution):** مقارنة المشكلات الشائعة لسكر الدايت التقليدي (المرارة بعد التذوق، التكتل، الحجم) مع حلول 4 Muscle.
   - **شبكة الاستخدامات اليومية (Use Cases):** 6 بطاقات دائرية تفاعلية (القهوة، الشاي، مشروبات البروتين، العصائر، الشوفان والزبادي، والحلويات).
   - **محدد الباقات التفاعلي (Interactive Bundles Selector):**
     - عبوة واحدة: 240 ج.م
     - 3 عبوات: 660 ج.م + شحن مجاني (الأكثر طلباً)
     - 4 عبوات: 880 ج.م + شحن مجاني
     - 5 عبوات: 1,100 ج.م + شحن مجاني
     - 6 عبوات: 1,320 ج.م + شحن مجاني + عبوة إضافية مجانية!
   - **جدول مقارنة الجودة (Comparison Section):** جدول مقارنة دقيق يتحول لبطاقات مكدسة على الهاتف لتجنب التمرير العرضي.
   - **آراء العملاء الموثقة (Testimonials Carousel):** شريحة تقييمات واقعية مأخوذة من لقطات محادثات العملاء الأصلية مع إمكانية معاينة صورة المحادثة.
   - **الأسئلة الشائعة (FAQ Accordion):** فتح سلس وإمكانية البحث الفوري عن أي استفسار مع زر مباشر لمحادثة الدعم عبر واتساب.

3. **سلة التسوق وإتمام الطلب (Commerce Flow):**
   - درج سلة التسوق المنزلق (Slide-over Cart Drawer) مع شريط تقدم مباشر يوضح المتبقي للحصول على الشحن المجاني.
   - صفحة سلة مستقلة `/cart`.
   - صفحة إتمام الطلب `/checkout` مع تدقيق فوري لأرقام الهواتف المصرية (11 رقماً) والعناوين، وقائمة كاملة بجميع المحافظات الـ 27 وتكاليف الشحن.
   - نظام كوبونات خصم مفعل ومحمي من السيرفر (كوبونات افتراضية للتجربة: `MUSCLE10` لخصم 10%، `HEALTHY50` لخصم 50 ج.م).
   - صفحة تأكيد الطلب `/order-confirmation` مع زر لمتابعة الطلب عبر واتساب برسالة مسبقة التجهيز.

4. **لوحة تحكم إدارية متكاملة (`/admin`):**
   - محمية بكلمة مرور مشفرة بملفات تعريف الارتباط (Session Cookie).
   - بطاقات إحصائية لإجمالي الطلبات، الطلبات الجديدة، قيد التجهيز، مع شركة الشحن، المستلمة، وإجمالي المبيعات بالجنيه المصري.
   - جدول طلبات تفاعلي يدعم البحث برقم الطلب، اسم العميل، الهاتف، أو المدينة مع فلاتر للحالة والمحافظة.
   - إمكانية تصدير الطلبات المفلترة إلى ملف **Excel (CSV)** مع دعم تام للأحرف العربية (BOM UTF-8).
   - صفحة تفاصيل الطلب `/admin/orders/:id`:
     - تعديل بيانات الشحن والعنوان مع نافذة تأكيد.
     - مسار الحالات المعتمد: `جديد` -> `تم التجهيز` -> `تم التسليم لشركة الشحن` -> `تم التسليم للعميل` -> `ملغي` / `مرتجع`.
     - إدخال اسم شركة الشحن ورقم بوليصة التتبع.
     - اشتراط ذكر سبب موثق عند إلغاء أو إرجاع أي طلب.
     - سجل تدقيق زمني كامل (Audit Trail Timeline) يسجل كل حركة وتعديل مع التوقيت واسم المنفذ.
     - طباعة إذن تسليم وشحن جاهز للطباعة (Packing Slip).
     - زر مراسلة فورية للعميل عبر واتساب.

## 🗄️ ربط سوبا بيز (Supabase Setup)

المشروع مصمم ليعمل محلياً بصورة كاملة بدون الحاجة لقاعدة بيانات، وحينما تصبح جاهزاً للربط مع حسابك الجديد في Supabase:

1. قم بإنشاء مشروع جديد في [Supabase](https://supabase.com).
2. ادخل إلى **SQL Editor** في لوحة تحكم Supabase.
3. انسخ محتوى الملف الموجود في المشروع:
   ```
   supabase/schema.sql
   ```
4. الصقه في محرر SQL واضغط **Run** (سيتم إنشاء الجداول: `orders`, `order_audit_logs`, `coupons` مع إعدادات الحماية RLS والأذونات تلقائياً).
5. من إعدادات مشروع Supabase (`Project Settings` -> `API`)، انسخ المفاتيح وضعها في ملف `.env.local` أو في إعدادات Vercel:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
   ```
بمجرد إضافة هذه المتغيرات، سيتحول المتجر تلقائياً لتخزين كافة الطلبات وسجلات التدقيق والكوبونات في Supabase مباشرة وبدون أي تعديل في الكود.

## ☁️ الرفع على فرسل (Deploy to Vercel)

1. ارفع المشروع إلى مستودع **GitHub** خاص بك:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for 4 Muscle store"
   git branch -M main
   git remote add origin https://github.com/your-username/4muscle.git
   git push -u origin main
   ```
2. ادخل إلى [Vercel](https://vercel.com) واضغط **Add New Project**.
3. اختر المستودع الخاص بك واضغط **Import**.
4. في قسم **Environment Variables**، أضف المتغيرات التالية:
   - `ADMIN_PASSWORD`: كلمة المرور التي تختارها لإدارة المتجر.
   - `NEXT_PUBLIC_SUPABASE_URL`: رابط مشروع Supabase الجديد.
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: المفتاح العام لـ Supabase.
   - `SUPABASE_SERVICE_ROLE_KEY`: مفتاح السيرفر لـ Supabase.
   - `NEXT_PUBLIC_WHATSAPP_NUMBER`: رقم واتساب المتجر (مثال: `201000000000`).
5. اضغط **Deploy**. سيبدأ المتجر بالعمل مباشرة على نطاق فرسل مع شهادة SSL مجانية وسرعة فائقة.
